HOW TO ADD IMAGES TO THE GUIDE
================================

Step 1: Save the Images
   - Save each screenshot with the corresponding filename above
   - Location: c:/xampp/htdocs/language-platform/exam-guide-assets/
   - Format: PNG (recommended for screenshots)
   - Size: No specific requirement, but 800-1200px width is ideal

Step 2: Update the HTML
   - Open exam-guide-with-images.html
   - Find each image placeholder (shown as dashed box with filename)
   - Replace the placeholder div with:
     <img src="exam-guide-assets/[filename].png" alt="[description]">

Step 3: Access the Guide
   - Open in browser: http://localhost/language-platform/exam-guide-with-images.html
   - Print to PDF: Ctrl+P → Save as PDF
   - Share: The URL can be bookmarked and shared with students

TIPS FOR SCREENSHOTS
====================

1. Capture the full interface/page content
2. Keep them consistent in size (800-1000px width)
3. Use PNG format for lossless compression
4. Remove any personal/sensitive data before adding
5. Use consistent lighting and contrast
6. Consider adding a subtle border or shadow
7. Name files descriptively and consistently

TROUBLESHOOTING
===============

If images don't appear:
1. Check image filenames match exactly (case-sensitive)
2. Verify images are in exam-guide-assets/ folder
3. Clear browser cache and refresh page
4. Check browser console for 404 errors
5. Ensure file permissions allow reading

If you need help:
- Check image paths in HTML
- Verify image files exist
- Test with simple <img> tag first
- Use browser developer tools (F12) to debug
